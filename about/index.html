About this directory

This starter is built to publish curated listings and supporting resources without carrying unrelated legacy product copy.

What is this site?

It is a searchable directory for curated listings, related resources, and optional editorial content. Each site built from this starter can tailor the brand, categories, routes, and supporting modules to its own product.

Our Mission

The goal of the starter is to give each site owner a clean, configurable foundation for publishing listings and supporting content. It aims to:

  • Keep the shared starter generic and reusable across multiple directory-style sites
  • Make site-owned branding, content, and optional surfaces easy to override
  • Provide a clear submission workflow for adding new listings
  • Support future expansion into guides, resources, and other site-owned experiences

How it Works

Define the site

Set the brand, routes, source data, and feature flags for the directory you want to publish.

Load listings

Bring in curated listing data, optional long-form content, and any supporting resource links you want to show.

Ship quickly

Publish a static directory with sensible defaults, then layer in site-specific content only where it adds value.
