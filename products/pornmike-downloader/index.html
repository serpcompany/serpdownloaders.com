Troubleshooting

The extension does not detect any video on the page. Make sure you are on a PornMike page that follows the /videos/&lt;slug&gt;-&lt;id&gt;/ URL pattern and that the video is playing.

The download button does not appear. Refresh the page and try starting the video playback again before opening the extension popup.

The download fails or stops midway. Check your internet connection and ensure the video stream is still active. Try restarting the download from the beginning.

The saved file does not play correctly. Try using a different media player, as some players have limited codec support. VLC Media Player is a reliable option.

The extension does not work on Firefox. Make sure you downloaded the Firefox-specific build from the latest release page. Each browser requires its own build.
