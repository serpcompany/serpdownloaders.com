#### FAQ

**Q: What types of content can I download?**
**A:** Videos (MP4, WebM, MOV, etc.), images (JPG, PNG, WebP, AVIF), GIFs, and text posts. The extension detects all media attached to Coomer posts.

**Q: How does it find content?**
**A:** The extension uses the Coomer API to scan posts programmatically. It extracts all attachments, file references, and text content from each post.

**Q: Can I download from a creator's entire page?**
**A:** Yes. On a creator page, the extension scans all visible posts (up to 60) and presents all media across tabs. Click "Download Visible" to bulk download.

**Q: Where are my downloads saved?**
**A:** All files save to a `Coomer Downloader/{creator name}/{date - title}` folder structure inside your browser's default Downloads directory.

**Q: Which Coomer domains are supported?**
**A:** coomer.su (primary), coomer.st, and coomer.party. The extension works across all three domains.

**Q: How many free downloads do I get?**
**A:** 3 free trial downloads after signing in with your email. Purchase a license for unlimited downloads.

**Q: Does this work on Firefox?**
**A:** Yes — supports Chrome, Edge, Brave, Opera, Whale, Yandex, and Firefox.

**Q: Are text posts really saved?**
**A:** Yes. Text content from posts is stripped of HTML, formatted with a title and metadata header, and saved as a .txt file in the creator's folder.

**Q: Is my data safe?**
**A:** Yes. All processing happens entirely in your browser. Authentication uses secure OTP — no passwords stored.
