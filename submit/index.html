Share the basics and we'll open a prefilled GitHub issue for review. No account is required on this site.

Submissions are reviewed through GitHub issues so the site can stay simple and easy to host.

Submission Tips

What reviewers need

  • •The main URL for the product you are submitting
  • •A short description that explains what the product covers
  • •Any helpful docs, examples, or support links in your reviewer notes

Best Practices

  • ✓Keep descriptions clear and concise
  • ✓Link to docs, examples, or support pages when they help reviewers
  • ✓Mention key features and capabilities
  • ✓Add reviewer notes when a submission needs extra context

Before you submit

Make sure the public URLs in this form are live and ready for review so the submission can be checked without follow-up.
